# 生きものの絵（原本）

ツリツリバースト v12 で使う、ステージごとの魚・レア魚・ヌシの原本画像です。

## なぜここに置くか

チャットに添付した画像は、**セッションが変わると消えます**。
そのため、**受け取ったら必ずこのフォルダに入れて push** します。
リポジトリに入っていれば、別のチャットでも `git clone` すれば必ず取り出せます。

## フォルダ

| フォルダ | 枚数 | なに |
|---|---|---|
| `batch1/` | 16 | 1回目に受け取ったぶん |
| `batch2/` | 16 | 2回目に受け取ったぶん |
| `batch3/` | 8 | 3回目に受け取ったぶん（生きもの） |
| `../backgrounds/` | 5 | ステージ背景3枚 ＋ v8からの原本2枚 |

生きもの **40 / 49体**。あと **9体**。

## 対応表

どの絵がどの生きものかは **`manifest.json`** にまとめてあります。
`confident: false` は絵から推測しただけなので、実装の前に本人に確認します。

## まよっているところ

- `batch3/1000016892.png`（銀白色の大きな魚＋黄金の月）を **ギンヅキダイ（満月★5）** と見ました。
  ただし仕様は「満月もよう」で、絵は三日月です。**ルナフィッシュ（レア魚）** の可能性もあります。
- `batch1/1000016922.png` を **ヒカリコ（深海★1）** と見ました。腹が青く光っているのは仕様どおりですが、
  絵にはチョウチンが付いています。仕様どおりの「チョウチンなしの黒い小魚」がよければ、これは予備になります。
- ふたごの入江の ★4 ハサミカマス / ★5 ツインバラクーダ は、どちらも銀色のカマス型で
  見分けがつきにくいため、尾びれの形で振りわけました（二股＝★4、二枚重ね＝★5）。逆でも成立します。

## 使うときの手順

1. 受け取った原本をこのフォルダに入れて push（**最優先**）
2. `manifest.json` の対応づけを本人と確認
3. 背景を抜き、ランクに応じた大きさで WebP に落として `fishing-v*.html` に埋めこむ
4. 原本はここに残したままにする（作り直しができるように）
