# 生きものの絵（原本）

ツリツリバースト v12 で使う、ステージごとの魚・レア魚・ヌシの原本画像です。

## なぜここに置くか

チャットに添付した画像は、**セッションが変わると消えます**。実際に v11 で使った
ステージ背景6枚は、次の作業のときにはもう残っていませんでした（ゲーム本体に
焼き込み済みだったので実害はありませんでした）。

そのため、**受け取ったら必ずこのフォルダに入れて push** します。
リポジトリに入っていれば、別のチャットでも `git clone` すれば必ず取り出せます。

## フォルダ

| フォルダ | なに |
|---|---|
| `batch1/` | 1回目に受け取った16枚。ファイル名は受け取ったときの番号のまま |

## 使うときの手順

1. 受け取った原本をこのフォルダに入れて push（**最優先**）
2. どの絵がどの生きものかを対応づけ、`manifest.json` に書く
3. 背景を抜き、ランクに応じた大きさで WebP に落として `fishing-v*.html` に埋めこむ
4. 原本はここに残したままにする（作り直しができるように）

## まだ足りないもの

- ステージ背景の差しかえ用：まんげつの湾／竜のたてあな／深海の大穴 の3枚
- 生きもの：全7ステージ × （ノーマル5 + レア魚1 + ヌシ1）＝ 49体ぶん
