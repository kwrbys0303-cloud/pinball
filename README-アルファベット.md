# アルファベット全集中 をリンクで配る

子どもがアルファベットを覚えるためのアプリです。
スマホ（iPhone / Android）で、**リンクを踏むだけ**で遊べます。

## URL

```
https://kwrbys0303-cloud.github.io/pinball/alphabet.html
```

このリンクを送れば、相手はログインなしで遊べます。
釣りゲームの URL（ https://kwrbys0303-cloud.github.io/pinball/ ）はそのままです。

## 入っているファイル

| ファイル | なに |
|---|---|
| `alphabet.html` | 配布用。URL が変わらないよう、いつも最新版をここにコピーする |
| `kimetsu-alphabet-v2.1.html` | 元データ（版つき）。直すときはこっち |

直したあとは、コピーしなおして push します。

```
cp kimetsu-alphabet-v2.1.html alphabet.html
```

`alphabet.html` を直接いじると、次のコピーで消えます。

## iPhone で遊ぶ

1. **Safari** でリンクを開く（LINE のブラウザではなく Safari で開くこと）
2. 下の共有ボタン（□に↑）→ **「ホーム画面に追加」**
3. ホーム画面に「全集中」のアイコンができる。押すとアドレスバー無しの全画面で起動する

**音が出ないとき**は、本体の横にある**マナーモード（消音）スイッチを解除**して、
音量を上げてください。アルファベットの英語読み上げは、最初に画面を一度
タップしたときから鳴りだします。音は画面右上の♪ボタンでいつでも切れます。

## Android で遊ぶ

Chrome で開く → 右上の「︙」→「ホーム画面に追加」

## オフラインについて

釣りゲームのページ（トップ）を一度でも開いていると、`sw.js` のしくみが
このアプリのページもキャッシュします。一度ひらいたあとは電波がなくても遊べます。
通信できるときは必ず最新を取りに行くので、更新すればすぐ新しくなります。

## 遊び方のメモ

- 階級は5つ。鬼殺隊員（大文字・小文字・読み方）→ 柱 → 上弦の鬼 → 縁壱 → 鬼化炭治郎 の順に難しくなる
- テンポは「ふつう／高速」。オープニングで切りかえる
- 愈史郎モードはアルファベット一覧。カタカナの読み方は表示・非表示を切りかえられる
- 速く答えるほど点が高い。ハイスコアはページを閉じるまでの記録
