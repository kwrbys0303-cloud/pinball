# 釉薬ガイド（教師用）

陶工室にある釉薬・化粧土・補助材を、知識ゼロから扱えるようにするための実務資料。
2026年11月24日時点の在庫にもとづく。生徒配布用の色見本は別ファイル「釉薬カタログ」を使う。

---

## 1. 釉薬とは何をしているのか

釉薬は、ごく単純化すると **「粉にしたガラスの原料を水に溶いた泥」** である。
焼成で起きていることは3段階。

1. **塗る** —— 素焼きの素地は無数の穴が空いたスポンジ状。そこへ泥を当てると、素地が水だけを吸い込み、固形分（ガラスの素）が表面に張り付いて残る。**吸水しているのは素地であって、釉が「くっついている」わけではない。**
2. **乾く** —— 水が抜け、粉の層（釉層）が素地に貼り付いた状態になる。この時点ではまだ粉なので、触ると取れる。
3. **焼く** —— 1200℃前後で粉が溶けてガラスになり、素地と一体化する。冷えて固まったものが、あの「つやつやの表面」。

ここから実務上の重要な帰結が3つ出る。

- **釉薬は腐らない。** 固まっていても、ひび割れていても、水を足せば元に戻る。捨てる必要はない。
- **厚みがすべてを決める。** 同じ釉薬でも、薄ければ下地が透け、厚ければ流れる。狙いは **乾燥後 0.8〜1mm**。
- **素地が水を吸えないと釉は乗らない。** 素焼き前の生地、油分や手の脂がついた面、一度濡らして吸水力を失った面には乗りにくい。

## 2. 固まった釉薬を使える状態に戻す

### 2-1. まず状態を3つに仕分ける

| 状態 | 所要時間 | 見分け方 |
|---|---|---|
| **A. 上に水が浮いている** | 15〜30分 | 透明な上澄み＋下に沈殿層 |
| **B. 全体がもったり固い** | 30〜60分 | 水は見えないが、押すと凹む |
| **C. カラカラに乾いてひび割れ** | 1〜2時間 | 塊が割れて乾いた粘土状 |

**一度に全部を戻そうとしない。** その日使う3〜4種類に絞る。

### 2-2. 手順

**A（上澄みあり）**
1. 上澄みの水を **捨てずに** 別容器に取る。これは釉の成分を含んだ貴重な水。
2. 下の固い層を、木べらで底からこすり上げるように練る。
3. 取っておいた水を少しずつ戻しながら濃度を合わせる。

**B（もったり）**
1. ぬるま湯を少量ずつ加えながら練る。一度に入れない。
2. 10分おいてなじませ、もう一度練る。

**C（完全乾燥）**
1. **先にぬるま湯を塊の上からかける。** —— 乾いた塊を先に砕くと **シリカ（石英）の微粉が舞う**。これは吸い込むと肺に悪い。粉じんを出さないことが第一。生徒に作業させるなら、必ず湿らせた後の工程から。
2. 40〜60分そのまま置いてふやかす（この間に生徒は別の作業へ）。
3. 木べらで崩して練る → さらに30分置く → 再度練る。
4. **必ず60メッシュ程度のふるい（茶こしでも可）で裏ごしする。** ダマが残ると、作品にブツや火ぶくれが出る。

### 2-3. 濃度を決める

専用のボーメ比重計があれば **1.45〜1.50**（泥漿の1.75〜1.80とは別の値なので混同しない）。
計器がなくても、次の2つで十分に実用になる。

- **流れ落ち方** —— ひしゃくですくって落としたとき、ポタポタではなく **とろりと糸を引いて落ちる**。
- **テスト片** —— 素焼きの破片を1秒浸けて引き上げ、乾いてから爪で引っかく。**白い筋が出る厚さ（約0.8〜1mm）** が適正。
  - 薄すぎ → 蓋をして30分沈め、上澄みを捨てて濃くする。
  - 厚すぎ → 水を足す。

**この確認を飛ばさない。** 1枚の破片で5分かければ、5人分の皿を守れる。

## 3. 釉掛けの手順

### 3-1. 下ごしらえ

1. 素焼き作品の **表面のホコリを固く絞った布で拭く**。素焼きの粉が残っていると釉がはじかれる。
2. **素手で触った脂も弾きの原因**。作業前に手を洗う。
3. 作品が湿っていないか確認。濡れていると吸水できず、釉が乗らない。

### 3-2. 掛け方（皿なら「浸し掛け」が最も安定）

1. 釉薬をよく撹拌する。**底に沈んだ重い成分（珪石・長石）が混ざっていないと色が出ない。**
2. 作品の **高台（底）を指2本で挟んで持つ**。
3. 釉の中へ **まっすぐ沈め、1〜2秒数えて、まっすぐ引き上げる**。ゆっくり出し入れするほどムラが減る。
4. 引き上げたら、余分が垂れきるまで3秒ほど上で保持。
5. 板の上に置く。**指で挟んだ跡は、乾いてから筆で同じ釉をちょんと置いて埋める。**

ひしゃくで内側だけ回し掛けする方法もあるが、生徒の作業としては浸し掛けのほうが失敗が少ない。

### 3-3. 高台の処理 —— 最重要

**釉が付いたまま焼くと、溶けたガラスで作品が棚板に溶着する。** 剥がすときに作品も棚板も壊れる。

- **釉掛け後、まだ濡れているうちに、濡れスポンジで高台（底の接地面）を拭き取る。**
- スポンジは **こまめに洗って絞る**。釉を含んだスポンジで拭くと、伸ばしているだけになる。
- 側面の下から **3mm程度まで** 拭いておくと、流れやすい釉でも安全。
- 生徒の手順としては「**底をきれいに拭く**」という独立した工程にすると定着しやすい。

## 4. 撥水剤と CP-M6 は別物

| | 撥水剤（ワックスレジスト） | CP-M6 水性水漏れ防止処理剤 |
|---|---|---|
| 使う時点 | **釉掛けの前** | **焼き上がった後** |
| 働き | 塗った部分が釉をはじく | 器に染み込んで水漏れを止める |
| 高台の釉よけに使えるか | **使える** | **使えない** |
| 乾燥 | 10〜20分 | 48時間程度 |

**2026年11月時点、陶工室に撥水剤は見当たらない。** 高台の処理は「濡れスポンジで拭き取る」で運用する。
撥水剤は1本2,000円程度なので、次年度の備品として購入を検討する価値はある。

## 5. 焼成温度 —— 在庫一覧と判断

| 釉薬 | 品番 | 適正温度 | 1230℃ |
|---|---|---|---|
| ペルシャブルー釉 | 255732 | 1,180〜1,200℃ | **過焼成** |
| エコ・ガラス釉 スカイブルー | 255778 | 1,200〜1,230℃ | ○ |
| 白天目釉 | 255702 | 1,200〜1,230℃ | ○ |
| 青いらぼ釉 | 255717 | 1,200〜1,230℃ | ○ |
| なまこ釉 | 255707 | 1,200〜1,230℃ | ○ |
| 茶天目釉 | 255706 | 1,200〜1,230℃ | ○ |
| 紫陽花釉 | 255773 | 1,200〜1,230℃ | ○ |
| ルリ釉 | 255721 | 1,200〜1,250℃ | ○ |
| オレンジ釉 | 255729 | 1,200〜1,250℃ | ○ |
| 高麗青磁釉 | 255-807 | 1,230〜1,250℃ | ○（下限） |
| 黒織部釉 | 256006 | 1,230〜1,250℃ | ○（下限） |
| 民芸釉薬（名称不明） | 不明 | 1,230〜1,250℃ | 要確認 |

### 結論：**1230℃ が最適解**

- 12種のうち **10種がこの温度で焼ける**。
- 高麗青磁・黒織部は適正範囲の下限なので、**やや発色が浅くなる可能性はあるが失敗ではない**。むしろ黒織部は低めのほうが流れにくい。
- **ペルシャブルー（1,180〜1,200℃）だけは適合しない。** 1230℃では釉が流れ、棚板に垂れ、色が飛ぶおそれがある。
  - 使いたい場合は、**小物1点だけを一番下の棚の、棚板に廃材を敷いた位置で** 試す。
  - あるいは今回は見送り、ペルシャブルーだけの低温窯を次回に組む。
- **民芸釉薬は銘柄不明のため使用を見送る。** テープを剥がして品番が読めたら次回から使える。

### なお「酸化焼成」で合っている

電気窯は酸化焼成。メーカーの見本写真も、カタログに採用したものは酸化焼成のサンプルを優先してある。還元焼成（ガス窯）の写真とは色が変わるので、見本を参照するときは注意する。

## 6. 11/30 釉掛け → 12/1 本焼き は可能か

**可能。ただし条件がある。**

- 釉層は **水が抜ければ焼ける**。常温・通常湿度で、浸し掛け程度の厚みなら **数時間〜一晩で乾く**。
- 11/30 の職業の時間（午前）に掛け終われば、12/1 の放課後まで **実質30時間前後**。十分な余裕がある。

**守るべきこと**

1. **11/30 のうちに全部掛け終える。** 翌日に持ち越さない。
2. 掛けた作品は **重ねず、風通しのよい棚に間隔を空けて並べる。**
3. 12/1 の窯詰め前に、**手で触って冷たくないか確認**。ひんやりする＝まだ水分がある。その作品だけ次の窯に回す。
4. 厚掛けしすぎた作品は乾きが遅い。濃度管理（2-3）をしておけば、この問題はほぼ起きない。

**水分が残ったまま焼くとどうなるか** —— 急激に水蒸気が出て釉層が吹き飛ぶ（釉はぜ）、またはピンホールだらけになる。だから3の確認を入れる。

---

## 7. 窯詰めの注意

- **作品どうしを接触させない。** 溶けた釉で溶着する。最低1cm空ける。
- **棚板に離型材（アルミナ）を薄く塗る**か、棚板が汚れていないか確認する。
- **流れやすい釉（ペルシャブルー・なまこ・黒織部）は下段を避ける**。垂れると下の作品にかかる。
- 窯出しは、**割れが怖いので教師のみで放課後に行う**（既定方針どおり）。

## 8. よくある失敗と原因

| 症状 | 原因 | 対策 |
|---|---|---|
| 釉が乗らない・はじく | 素地に脂・ホコリ、素地が湿っていた | 拭く・手を洗う・乾かす |
| ピンホール（針穴） | 釉層に水分が残っていた／素地のガス抜け不足 | 乾燥時間を確保／素焼きを十分に |
| 釉はぜ（焼成中に剥離） | 厚すぎ／乾燥不足 | 0.8〜1mmを守る |
| 流れて棚板に垂れた | 厚すぎ／温度が適正範囲の上を超えた | 濃度と温度を見直す／高台まわりを広めに拭く |
| 色が薄い・下地が透ける | 薄すぎ／撹拌不足で成分が沈んだまま | 濃度を上げる／掛ける直前に必ず撹拌 |
| ムラになった | 出し入れが速い／途中で止めた | まっすぐ・一定速度で沈めて上げる |
| 棚板に溶着した | 高台の拭き取り不足 | 底＋側面下3mmまで拭く |

## 9. 化粧土・練り込み絵の具・本焼絵具・カレットグラス

**それぞれ使う工程が違う。** ここを間違えると全部無駄になる。

| 材料 | 使う工程 | 中身 |
|---|---|---|
| **練り込み絵の具**（黒 1kg） | **生粘土に練り込む** | 顔料。色粘土をつくる。たたら引きの段階で白土に混ぜれば、大理石模様や象嵌ができる |
| **化粧土**（白化粧泥 1L、1,180〜1,300℃） | **生乾きの生地に塗る**（素焼き前） | 白い泥。赤土の上に塗って白くする、刷毛目・スポイトで模様を描く |
| **釉薬** | **素焼きのあと** | 本資料の主題 |
| **本焼絵具**（T-519サーモンピンク／T-508オレンジ／ピンクG-50 ほか） | **本焼きのあと**、釉の上に描いて再度低温で焼く（上絵付） | 絵具。800℃前後で焼き付ける |
| **カレットグラス** | 成形時〜釉掛け時に器の凹みに置く | 色ガラスの粒。溶けて水たまりのような透明層になる |

**2026年11月時点の重要な結論：化粧土と練り込み絵の具は、今期の素焼き済みの皿には使えない。**
素焼き済みの素地は水をほとんど吸わないため、化粧土を塗っても密着せず、焼成中に剥がれる。

**3学期の新作から、たたら引きの段階で導入する。** これは表現の幅が一気に広がるので、独立した単元にする価値がある。

## 10. 当日の段取り（90分想定・標準形）

| 時間 | 内容 | 教師の位置 |
|---|---|---|
| 〜開始前 | 教師が釉薬を戻しておく（2章） | 準備 |
| 0〜10分 | カタログを見せ、1人ずつ色を決める。名簿に記録 | 全体 |
| 10〜20分 | **素焼き片でテスト掛け**、濃度確認 | 釉薬の前 |
| 20〜70分 | 1人ずつ順番に。浸す → 引き上げる → **底を拭く** → 板に並べる | 釉薬の前（離れられない） |
| 待ち時間 | 乾いた作品のバリ取り・表面みがき、片付け | 巡回 |
| 70〜90分 | 容器の蓋を閉める、スポンジ・バケツを洗う、床を拭く | 巡回 |

**釉薬の前から離れられない時間が約50分ある。** 待ちの生徒には、先に「待ちのしごと一覧表」から1つ選ばせておく。
