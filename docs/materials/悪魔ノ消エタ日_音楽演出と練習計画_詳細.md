## 4．戦い（場面3）の組み立て ― いちばん難しいところ

### 問題
90秒の音源は止まってくれない。動きが遅れると、音楽が終わっているのにまだ戦っている、早いと音楽だけが残る。

### おすすめ：「ジャーン」は生の楽器で鳴らし、音源はそこで止める
- BGMを**2分くらいの長さにしておく**（編集ソフトでくり返しをつなぐ）。音源が先に終わってしまう心配がなくなる
- 家来リーダー（野村）がひざをついた瞬間に、**楽器隊が生で★ジャーン**（大太鼓＋シンバル＋ウクレレ全員）
- 操作の先生は、ジャーンと同時にBGMを止める（PowerPointでクリック1回。先生は舞台を見ていればよい）
- 生徒は「音楽の何秒」を気にしなくていい。**野村のひざ＝ジャーン**、これだけ覚えればよい

### 動きの順番（だいたいの時間の目安。練習で測って調整）

### 「セリフの間は弱める」を生徒が覚えられるルール
- **合図は「話す人が一歩前に出たら、小さく」「話し終わって動き出したら、大きく」**。先生の合図はいらない。舞台を見ていればわかる
- 音の大きさを「3」「1」と数字で呼ぶ。3＝全開、1＝ささやき。練習で「3→1→3」を何度もやる（ゲームにする）
- ウクレレの「1」の弾き方：弦を軽くおさえて「チャッ、チャッ」と短く刻む（ミュート）。音が小さくても、リズムは止まらないので、戦いの勢いは続く。これが「高等テクニック」として見映えする

## 5．糸・カントリーロードを見栄えよくする

### 声が小さい対策（声以外で支える）
1. **マイクの立て方**：ウクレレを持っているので手持ちマイクは使えない。高めのスタンドマイクを2〜3本、全員が半円にぎゅっと集まった中心に立てる。間が空くと声は拾えない
2. **ウクレレにもマイク**（先生の方針どおり）：ウクレレ隊の前にもう1本。ウクレレの音が大きく聞こえると、自信がついて声も出やすくなる
3. **歌詞は完全に覚える**：下を向くと声は半分になる。客席の後ろの壁に、大きな歌詞を貼る（顔が上がる）
4. **録音ピアノに先生の「仮歌」をごく小さく入れる**（任意）：生徒の声を支える「安全ネット」。大きすぎると口パクに見えるので、生徒の声より必ず小さく
5. **歌い出しとサビの最初の言葉だけ全力**：「なぜ」「縦の糸は」「カントリーロード」。全部を大きくしようとすると続かない。一番目立つところだけ
6. **キーの確認**：今のキーで高すぎ・低すぎの人がいないか、10月中に確認。高すぎると声が細くなる

### 見え方
- 歌うときの姿勢を決める：足を肩幅、ウクレレは胸の高さ、顔は客席の後ろの歌詞
- 王女・剣士は前で手話・動作。2人とも客席を向く（見つめ合わない）
- 糸のサビだけ、ウクレレ隊も顔を上げて客席を見て弾く（ここが「輝いている姿」）
- カントリーロードの最後は全員で一歩前へ → ジャン！ → 決めポーズ

## 6．「稚拙に見えない」ために

1. **セリフ → 決めの姿勢（2秒）→ 戻る、を必ずセットで**：先生の考えのとおり、とても効果的。言い終わったあと、すぐ動いたり、もじもじしたりすると稚拙に見える。止まると「わざとやっている」＝演出に見える
2. **セリフを言う前の「一歩」**：前に一歩出てから言う。毎回同じ動きなので、迷わない
3. **出入りと待ち方を決める**：出番でないときの姿勢（家来はひざまずく、楽器隊は楽器を構えて静止）。舞台上の全員が「止まっている」と、話している人だけが目立つ
4. **無音を怖がらない**：大太鼓のあと、ジャーンのあと、おにぎりのあと。音がないところが一番引き締まる
5. **楽器隊は「楽団」として振る舞う**：始まる前にそろって座る、終わりに楽器を下ろす動きをそろえる。それだけでプロっぽく見える
6. **衣装は少しだけ**：王女のティアラ、剣士のマント、家来の武器。全部作り込まなくても、「変身スイッチ」になる

## 7．恥ずかしさとの向き合い方（高等部だからこそ）

- **「笑われる」ではなく「笑わせる」**：笑いの場面は、お客さんを笑わせる「仕事」だと伝える。笑いが起きたら成功
- **役になる＝自分ではない**：衣装・小道具を身につけたら「役の人」。恥ずかしいのは自分ではなく役
- **先生がまず全力でやって見せる**：先生が恥ずかしがらずに王女のセリフを言うと、空気が変わる
- **本物を少し見る**：ミュージカルや劇団の映像を1〜2分だけ見る。「大げさにやるのがかっこいい」と知る
- **見られる段階を少しずつ上げる**：グループ内 → 先生 → 他の学年 → 本番。いきなり大勢に見られない
- **良いところだけ録画で見る**：最初の録画は、良いところだけを見せる。直すところは次から
- **逃げ道もつくる**：どうしても恥ずかしいところは、楽器や手話で表現してよい
- **言葉を変える**：「劇の練習」ではなく「キャスト練習」「楽団練習」。高等部らしいプロの言葉を使う
