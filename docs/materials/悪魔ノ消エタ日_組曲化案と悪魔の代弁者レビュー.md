# 「悪魔ノ消エタ日」組曲化案と、悪魔の代弁者レビュー（2026年10月9日）

## 結論
「ずっと演奏し続ける組曲」は正しい方向。ただし「同じ音量でずっと鳴っている」とうるさく、セリフも聞こえない。
**音を3段階に切り替える（フル／伴奏／無音）**ことで、ずっと演奏している一体感と、セリフが聞こえることを両立させる。
演劇の伴奏音楽（アンダースコア）と同じ考え方。

## 1．新しい形：組曲「悪魔ノ消エタ日」

プログラムやスライドでは「組曲」として紹介する。各場面を「第〇曲」と呼ぶ。

| 曲 | 場面 | 中身 | 主役の音 |
|---|---|---|---|
| 序曲 | プロローグ | 悪ノ娘（ピアノ）→ ウクレレ隊がCで入る | ピアノ → ウクレレ |
| 第1曲「王女のマーチ」 | 場面1 | C・Am・F・G7 の行進 | ウクレレ（刻み）＋鍵盤ハーモニカ・カスタネット |
| 第2曲「心臓の音」 | 場面2 | Am・F・G7 をゆっくり | ボンゴの心臓の音 |
| 第3曲「戦いのロンド」 | 場面3 | 速い4コード | ボンゴ＋ウクレレ（呼びかけとこたえ） |
| 第4曲「はんぶんこ」 | 場面4 | C・Am・F・G7 をとてもゆっくり | ウクレレのアルペジオ |
| 歌① | 糸 | 全員で歌う | ウクレレ11本＋ピアノ＋歌 |
| 第5曲「新しい道」 | 場面5 | YELL（ピアノ） | ピアノ（ウクレレは休み・構えて待つ） |
| 歌②・終曲 | カントリーロード | ウクレレだけの前奏 → 全員で歌う → ジャン！ | ウクレレ全員＋打楽器＋手拍子 |

### 音の3段階（いちばん大事なルール）

| 段階 | いつ | 録音BGM | ウクレレ |
|---|---|---|---|
| ①フル | 前奏・場面の切りかえ・戦い・歌 | ふつう | ジャカジャカしっかり |
| ②伴奏 | 語り・セリフの間 | 小さく（音響が下げる） | 1小節に1回だけ「ジャーン」とのばす |
| ③無音 | 「聞こえないのかしら」の直前、戦いの決着のあと、「おいしい」の前 | 止める | 止める |

- **セリフとセリフのすき間に、ウクレレが「ジャン！」と相づちを入れる**（呼びかけとこたえ）。セリフの上には重ねない。セリフ → ジャン → セリフ、と交互にすると、「劇」ではなく「音楽の中で話している」ように見える。これが音楽的な見せ場になる。
- 先生（T1）が客席側から手で合図する：**パー＝フル、グー＝1回だけ、手を下に＝止め**。色カードはコード。
- 録音BGMの音量は、**いつもウクレレの生音より小さく**。BGMはウクレレの「支え」であって、主役ではない。

### 目線の整理（どこを見ればいいか）
- ウクレレ隊は舞台の下手側に「楽団」として固定。役者は中央〜上手。
- 話す人だけがマイクの位置（セリフスポット）に出る。話す人に照明を当てられるなら当てる。
- 伴奏中のウクレレ隊は、話している人の方を向いて弾く（観客の目線も自然にそちらへ向く）。
- 場面の切りかえ（フル）のときだけ、ウクレレ隊が客席を向いて堂々と弾く ＝ 観客が「楽団」を見る時間。

### 切りかえの段取り（音響）
- 「悪ノ娘（ピアノ）＋その場面のBGM」を**1つのファイルにつなげておく**。ボタン1回で、悪ノ娘 → BGMのイントロ2小節 → コード、と進む。すき間や押し間違いを防げる。
- BGMの音量を上げ下げする場所を、キュー台本に「BGM↓」「BGM↑」と書いておく。

### ウクレレだけの見せ場（はっきり作る）
1. 序曲：悪ノ娘のあと、ウクレレ隊だけで C を4小節（BGMはまだ入れない）→ そこからBGM。
2. 戦い：ボンゴ「ドドン」→ ウクレレ「ジャカジャン」の掛け合い。
3. カントリーロードの前奏：ウクレレ11本だけ。
4. 最後の「せーの！ジャン！！」。

## 2．悪魔の代弁者レビュー（問題点と改善策）

### A．観客の立場から
| 問題点 | 改善策 |
|---|---|
| ずっと音が鳴っていて、セリフが聞き取れない | 音の3段階。セリフの間はBGMを下げ、ウクレレは1回のばすだけ。セリフの上に音を重ねず、すき間で相づち |
| 7分間同じような音でずっと鳴っていると、単調で飽きる | 場面ごとにテンポ・楽器・弾き方を変える（行進・心臓・戦い・アルペジオ）。無音の瞬間をわざと入れる |
| 話の筋がわからない（小学部の子・初めて見る保護者） | スクリーンに場面タイトルと語りの字幕。語りだけで筋がわかるようにしてある |
| どこを見ればいいかわからない | 楽団（下手）と役者（中央）を分ける。話す人だけ前に出る。ウクレレ隊は話す人の方を向く |
| 体育館ではウクレレの生音が後ろまで届かない | ウクレレ隊の前に集音マイクを1〜2本。またはBGMをかなり小さくして、相対的にウクレレを大きく聞かせる。**本番会場で必ず音のバランスを確認する** |
| 「悪ノ娘」を知る人には暗い話に見える | 使うのはイントロだけ。話はプリンとおにぎりで、明るく終わる |

### B．生徒の立場から
| 問題点 | 改善策 |
|---|---|
| ウクレレを弾き続けて疲れる・手が痛い | 「伴奏」の間は1小節1回なので休める。場面5（YELL）はウクレレを休む |
| BGMのテンポにウクレレがついていけず、ずれる | 録音BGMはイントロ2小節で数えて入る。ずれても戻れるよう、各コード2小節以上の場面を多めに。それでも厳しければ下の「C．案」へ |
| 語り部は「話す」と「弾く」が重なって混乱する | 話すときは弾かない（ほかの人が続ける）。語り部の4人のうち、話す人以外が弾く |
| 家来は戦いのあとウクレレに持ち替えるので、あせる | 糸の前奏8小節。ウクレレ置き場と膝立ちの位置をテープで決める。持ち替えだけの練習 |
| 奥平さんが練習に来られず、音楽に合わせる練習ができない | 練習の録画と音源を渡す。音楽との合わせは「〇小節目で言う」ではなく「ジャン！のあとに言う」にして、合わせやすくする |
| 玉井さん・西井さん・大畑さんの声が通らない | セリフスポットのマイク。セリフの前は音を下げる・止める。字幕 |
| 「自分らしさ」が音楽にない（役者以外） | ウクレレの刻み方を場面ごとに生徒が考える（音楽づくり）。大塚・吉川は効果音の楽器を自分で選ぶ |

### C．音楽の先生の立場から
| 問題点 | 改善策 |
|---|---|
| 録音BGM＋生演奏は、テンポが固定されて「生徒に合わせられない」 | **案：本番はT2のピアノが録音BGMの代わりに同じコード進行を生で弾く。** 録音BGMは練習用と、場面の切りかえだけに使う。生のピアノなら、生徒がずれても合わせられる。どちらにするかは11月の通しで決める |
| AI生成の音源が4コードからはみ出す | 先生がウクレレで合わせて確認。合わない部分は使わない |
| 音楽として評価しにくい（劇が主になる） | 「器楽（ウクレレ・打楽器）」「歌唱（糸・カントリーロード）」「音楽づくり（場面に合う弾き方・効果音を考える）」の3つを、場面ごとに学習目標として位置づける |
| 糸・カントリーロードのキーが生徒の声に合わない | ウクレレの4コードで弾けるキー（C）で歌うと高すぎ／低すぎにならないか、10月中に確認 |

### D．担当の先生・学校の立場から
| 問題点 | 改善策 |
|---|---|
| 本番中に操作することが多すぎる（音源・音量・スライド・合図） | 先生4人で分担：T1合図、T2ピアノ、T3音響（音源と音量）、T4スライド・袖。音源は場面ごと1ファイル |
| 練習時間が足りない（音楽9回＋朝の文化祭練習20分×19回） | 優先順位：①ウクレレのコード（全員）②語りとセリフのマイク練習 ③場面の切りかえ ④動き。動きは最後でよい |
| 機材トラブル（音が出ない） | 音源はPCとスマホの2台に入れておく。止まったら、T2がピアノで同じコードを弾いて続ける |
| 「奪いなさい」「鉄砲」など、学校の発表として気になる言葉 | 最後に謝りに行く話なので、筋としては問題ない。鉄砲はおもちゃとわかる作りにする（色や形でコミカルに） |
| 著作権 | 校内の無料の文化祭での演奏・上演は可。録音音源も入手経路が正しいものを使う。録画を配信するなら別に確認。AI生成音源はその生成サービスの利用規約を確認 |
| 8分をこえる | 毎回時間を計る。こえたら序曲と場面2のBGMを短くする |

### E．「稚拙に見えないか」という視点
| 問題点 | 改善策 |
|---|---|
| 劇の演技は上手にならないかもしれない | 演技で見せず、**音楽と「間」で見せる**。セリフは短く、決めゼリフのあとは音で受ける。ウクレレの見せ場を4つはっきり作る |
| 生徒がもじもじして見える | 立ち位置と、セリフを言ったあとの「決めの姿勢」を決めておく。迷う時間をなくす |
| 最後がそろわないと台無し | 「せーの！ジャン！」だけを毎回の練習の最後に3回。成功体験で終わる |

## 3．10月中に決めたいこと
1. 本番の伴奏は、録音BGMにするか、T2の生ピアノにするか（両方用意して、11/26の通しで決める）
2. ウクレレ隊の集音マイクを使うか（体育館で音を出して確認）
3. 先生の合図の出し方（パー・グー・手を下に）
4. 各場面のウクレレの弾き方（生徒と一緒に決める＝音楽づくりの時間）
