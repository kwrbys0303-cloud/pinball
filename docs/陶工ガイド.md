# 陶工ガイド（先生の自主練習用）

このガイドは、陶工が初めての先生が、生徒に教える前に**自分の手で一度やってみる**ための手引きです。
「なぜそうするのか」を添えているので、生徒に説明するときの言葉にもそのまま使えます。

対象の3工程：
1. 土練り（荒練り・菊練り）— 手で空気を抜く
2. たたら引き（スラブ成形）— シートを型にはめてお皿・お椀を作る
3. 流し込み（鋳込み）— 泥漿を型に流して花瓶・置物を作る

---

## 1. 土練り（荒練り・菊練り）

### なぜ練るのか

粘土の中には、袋から出したままだと**目に見えない空気の粒**と**硬さのムラ**が必ず入っている。
このまま成形したり焼いたりすると、

- 空気が焼成中に膨張して**破裂・ひび割れ**の原因になる
- 硬さにムラがあると、乾燥時の縮み方が均一にならず**歪み・割れ**の原因になる

練る作業は、地味だが**この2つの事故を防ぐための唯一の工程**である。

### 準備するもの

- 練り台（吸水性のある石膏板、または木の台に布を張ったもの。粘土がベタつかない面がよい）
- 切り糸（両端に持ち手が付いたワイヤー）
- 霧吹き（乾燥している場合に少量の水を足す用）
- 体重をかけられる高さの台（低すぎると腰を痛める）

### 荒練り（あらねり）— まずはここから

**目的**：粘土全体の硬さを均一にする。大きな空気の塊を潰す。

**手順**
1. 粘土を練り台に置き、両手で押しつぶすように**手前から奥へ体重を乗せて押し出す**。
2. 押し出した粘土を手前に丸め戻し、また押し出す。これを繰り返す。
3. **腕の力ではなく、体重（特に肩・上半身）を使う**のがコツ。腕だけだとすぐ疲れて、力も弱い。
4. 5〜10回ほど繰り返したら、いったん**切り糸で真っ二つに切る**。切り口に丸い穴（気泡）が見えないか確認する。
5. 気泡が見えたら、その断面を上にして押しつぶし、また同じ動作を繰り返す。気泡が消えるまで続ける。

**ポイント**
- 「練れているかどうか」は感触ではなく**切って目で確認する**。感触だけで判断しようとすると失敗しやすい。
- 粘土が硬すぎる（ひび割れながら伸びる）場合は、霧吹きで少量ずつ水を足しながら練る。柔らかすぎる場合は、少し置いて乾かすか、乾いた粘土を混ぜて硬さを調整する。

### 菊練り（きくねり）— 荒練りの後の仕上げ

**目的**：残った細かい空気を完全に抜く。粘土の中の粒子の向きをらせん状に揃えて、成形しやすい状態にする。

**手順（右利きの場合の一例）**
1. 荒練りした粘土を両手で包むように持つ。
2. **右手のひらの付け根（手首に近い部分）で粘土の中心を斜め下に押し込む**。このとき、左手は粘土を軽く支えて回転させる役目。
3. 押し込んだら粘土を**左方向にわずかに回転**させ、また同じ場所を押し込む。
4. この「押し込む→少し回す→押し込む」を一定のリズムで繰り返すと、粘土の表面に菊の花びらのような渦の模様ができてくる。
5. 20〜30回ほど繰り返したら、最後に**円錐形にまとめて先端を軽くねじり切る**ようにして仕上げる。

**うまくいかないときのチェックポイント**

| 症状 | 原因 | 対策 |
|---|---|---|
| 模様ができず、ただこねているだけになる | 押す位置が毎回バラバラ／回転させていない | 押す場所を「粘土の中心のやや手前」に固定し、押す→回すのリズムを一定にする |
| 粘土が横に広がるだけで丸くまとまらない | 力を**真下**ではなく**斜め下**にかけられていない、または力が強すぎる | 力の方向を意識する。強く押しすぎず、体重を乗せる感覚で |
| かえって空気が入ってしまう | 押し込んだ後、**元の丸い形に戻すときに空気を巻き込んでいる** | 粘土を丸め直すときに、表面をなでるように閉じる。叩きつけて丸めない |
| 疲れて続かない | 腕の力だけで押している | 手のひらの付け根と体重を使う。膝を軽く曲げて腰を落とすと体重が乗せやすい |

**最終チェック**：菊練りが終わったら、もう一度切り糸で切って断面を確認する。気泡が完全になくなっていれば合格。

### 自主練習メニュー（学期前におすすめ）

1. くず土（失敗作・端材）を使って、荒練り→切って確認、を**気泡が見えなくなるまで**繰り返す。
2. 菊練りは、最初は模様を作ることより**「押す→回す」のリズムを一定にする**ことだけに集中して10分練習する。
3. 慣れてきたら、練った粘土を再び潰して混ぜ、もう一度練り直す（これを繰り返すほど上達する）。
4. 練った粘土の中央を指で押して、**耳たぶくらいの柔らかさ**になっているか確認する（陶芸でよく使われる目安）。

### 生徒に教えるときのポイント

- 高等部の生徒には**菊練りの完璧な模様は求めなくてよい**。ねらいは「空気を抜く」ことなので、荒練り＋簡易的な練りで十分。
- 「押す→回す」を声に出してリズムを取ってあげると、動作が揃いやすい。
- 手先が不器用な生徒には、**荒練り（押しつぶす動作）だけを担当させ、菊練りの仕上げは教員が行う**という分担も現実的。
- 切って気泡を確認する作業は、生徒にとって「できた／できていない」が目で見てわかる、**達成感を持たせやすい工程**。積極的にやらせるとよい。

## 2. たたら引き（スラブ成形）

### 準備するもの

- たたら板（同じ厚みのものを2枚。今回は7mm厚を想定）
- 麺棒、または切り糸（弓状のたたら引き用ワイヤー）
- 木槌または手のひら（粘土を軽く叩いて平らにする下準備用）
- 布またはビニールシート（粘土が台にくっつかないように敷く）
- 石膏型・素焼き型（お皿・お椀の形）
- なめし革、スポンジ（表面をなでる用）
- スタンプ・型押し道具
- 切り出しナイフ、なで刷毛（接着面に使う「どべ」用の刷毛。今回は型はめ中心なので必須ではない）

### 手順

**① たたらを引く**
1. 練った粘土を布の上に置き、手のひらで軽く叩いて平らにしておく。
2. 粘土の両脇に、同じ厚みのたたら板を1枚ずつ置く。
3. 麺棒（または弓状のワイヤー）を、両脇のたたら板の上を滑らせるようにして粘土の上を転がし（または引き）、**板と同じ厚みの均一なシート**を作る。
4. たたら板を使うことで、**厚みが端から端まで一定になる**のがポイント。目分量で伸ばすと、必ず厚みにムラが出て乾燥・焼成時の割れにつながる。

**② 型にはめる**
1. できたシートを、石膏型（お皿・お椀の凹型または凸型）の上にそっと乗せる。
2. **中心から外側に向かって、指の腹かスポンジで軽く押さえていく**。一気に端まで押さえず、少しずつ空気を外に逃がすように押していく。
3. 型の縁からはみ出た余分な粘土は、切り出しナイフで型に沿って切り落とす。**少し余裕を持たせて切り、乾燥後に整える**方が安全（ぴったり切りすぎると縁が欠けやすい）。

**③ スタンプでオリジナリティを加える**
- **一番きれいに押せるのは、シートを型にはめる「前」の、まだ平らな状態のとき**。手のひらで下から軽く支えながら、上からまっすぐスタンプを押し当てる。
- 型にはめた後にスタンプを押す場合は、下が曲面になっているため力が均等にかかりにくい。押す場所の下に手を添えて支えながら、垂直に押す。
- 力を入れすぎるとシートに穴が開いたり、型からはみ出たりするので、**「トン」と軽く一度で押して離す**のがコツ。何度も押し直すと模様がぶれる。

**④ 乾燥**
1. 型にはめたまま、**半日〜1日**、風の当たらない場所で乾燥させる（急激な乾燥は割れの原因）。
2. 完全に乾かす前に、粘土が**「革のような硬さ（革状）」**になった時点で型から外す。爪で押すとわずかにへこむが、形は崩れない硬さが目安。
3. 型から出した後は、**乾燥しすぎないようにビニールを軽くかぶせて**、次回の授業まで縁の処理ができる硬さを保つ。

### よくある失敗と対策

| 症状 | 原因 | 対策 |
|---|---|---|
| 型にはめる途中でシートが裂ける | 一気に伸ばしすぎている／シートが薄すぎる | 中心から少しずつ外側へ、押さえる範囲を広げていく。たたら板の厚みを7mm以上にする |
| 型とシートの間に空気が入ってふくらむ | 中心からではなく端から押さえてしまい、空気の逃げ場がなくなった | 必ず中心から外側へ。ふくらみに気づいたら、その部分だけ針で小さく穴を開けて空気を抜く |
| 縁が乾燥中にひび割れる | 乾燥が速すぎる（特に薄い縁は乾きやすい） | 縁だけビニールを少し多めにかぶせ、本体より乾燥を遅らせる |
| スタンプの模様がぼやける、二重になる | 押した後に手元がぶれた、または押し直した | 一度で押して垂直に離す。練習で「一発勝負」の感覚をつかんでおく |
| 型から外すときに割れる・変形する | 乾燥が足りず柔らかすぎる状態で外そうとした | 「革状」まで待つ。爪で押して形が戻らない硬さになってから外す |

### 自主練習メニュー

1. たたら板で7mm厚のシートを1枚引いてみて、定規で数か所の厚みを測り、ムラがないか確認する。
2. 同じシートを使って、型にはめる練習を2〜3回繰り返す。空気が入ったときの「ふくらみ」の感触を覚えておく。
3. スタンプを、型にはめる前・はめた後の両方で押してみて、仕上がりの違いを比較する。
4. 型から外すタイミングを変えて（半乾燥・完全乾燥）2パターン試し、割れやすさの違いを体感する。

### 生徒に教えるときのポイント

- **「中心から外へ」だけは繰り返し言葉で伝える**。ここを守れば大きな失敗はほぼ防げる。
- スタンプは「一発で押す」を教員が先に見本を見せてから生徒にやらせると、失敗が減る。
- 縁の切り落としは危険（ナイフを使う）なので、最初は教員が線を描いてなぞらせる、または教員が仕上げるところまで支援する。
- 手先が不器用な生徒には、型にシートを乗せた後の**「押さえる」動作だけ**を任せ、型はめの位置合わせやシート引きは教員が行うなど、工程を分担するとよい。

## 3. 流し込み（鋳込み・スリップキャスト）

### 準備するもの

- 泥漿（でいしょう）：くず土を水に溶いたクリーム状の粘土液
- 攪拌機（今回は使用予定）
- 篩（ふるい）60〜80メッシュ程度（ゴミや塊を取り除く）
- 解膠剤（かいこうざい）：珪酸ソーダや炭酸ソーダなど。少量の添加で泥漿の流動性を上げ、水分量を抑えられる
- ボーメ比重計（泥漿の濃度を数値で確認する道具）
- 石膏型（複数のパーツを組み合わせるタイプが多い）
- 型を固定するゴムバンドまたはベルト
- 排泥用のバケツ、受け皿
- 切り出しナイフ（バリ取り用）

### 手順

**① 泥漿を作る（攪拌）**
1. くず土を細かく砕き、水と一緒に攪拌機に入れる。
2. しばらく撹拌し、ダマがなくなり均一なクリーム状になるまで混ぜる。
3. 篩に通して、溶け残りの塊や異物を取り除く。
4. **解膠剤を少量ずつ加えながら様子を見る**。入れすぎると逆に流動性が落ちるので、加える→混ぜる→様子を見る、を少しずつ繰り返す（この調整は教員が事前に行うのが安全）。

**② 比重を確認する**
1. ボーメ比重計を泥漿に浮かべ、数値を読む。**目安は1.75〜1.80程度**（型や粘土の種類によって最適値は変わるので、実際に使う型・粘土で試して自分の基準を作っておくとよい）。
2. 濃すぎる（比重が高すぎる）と流れが悪く気泡が入りやすい。薄すぎる（比重が低すぎる）と壁が厚くなるまでの時間が長くかかりすぎる。

**③ 注入する**
1. 型のパーツを合わせ、ゴムバンドでしっかり固定する（隙間があると泥漿が漏れる）。
2. 泥漿を、**型の注ぎ口の縁を伝わらせるようにゆっくりと**注ぐ。勢いよく真下に注ぐと、空気を巻き込んで気泡の原因になる。
3. 型の口いっぱいまで注いだら、少し置く。**石膏が水分を吸うため、液面が下がってくる**ので、下がった分を継ぎ足す（1〜2回)。

**④ 着肉を待つ（着肉時間）**
1. 型の内側の石膏が水分を吸うことで、内壁に粘土の層（肉）が少しずつ厚くなっていく。
2. **待ち時間の目安は、小さいもの（小さな花瓶など）で15〜20分、大きめの置物で30分以上**。ただし型の吸水性・泥漿の濃度・気温で変わるため、**必ず自分の型・自分の泥漿で一度試し、断面を切って厚みを確認してから本番の時間を決める**こと。
3. 待っている間は型を動かしたり傾けたりしない。

**⑤ 排泥する**
1. 型をゆっくりと逆さにして、中の余った泥漿を排泥用バケツに流し出す。
2. 一気に傾けず、**型を回しながら少しずつ角度をつけて**、内壁に均一に泥漿が伝いながら抜けるようにする。
3. しばらく逆さのまま置いて、垂れてくる泥漿がほぼ止まるまで待つ。
4. 排出した泥漿はバケツで回収し、次回また使える（ただし異物混入に注意）。

**⑥ 型抜き**
1. 排泥後、しばらく置いて**内側の粘土が自立できる硬さ（縁を触ってもへこまない程度）**になるまで待つ。
2. ゴムバンドを外し、型を静かに開く。パーツごとにゆっくり離す。
3. 型と作品の継ぎ目にできる線状の**バリ**を、切り出しナイフや竹べらで軽くなでるようにして取り除く。

### 着肉時間の目安と調整方法

| 状況 | 対応 |
|---|---|
| 壁が薄すぎる（もろい・すぐ割れる） | 着肉時間を延ばす、または泥漿の比重を少し上げる |
| 壁が厚すぎる（重い・乾燥に時間がかかる） | 着肉時間を短くする |
| 型によって仕上がりが違う | 型ごとに吸水性が異なるため、**型に番号を振って着肉時間を記録しておく**と安定する |
| 毎回時間がバラバラになってしまう | タイマーを使い、注入完了の瞬間からきっちり計測する。目分量で判断しない |

### よくある失敗と対策

| 症状 | 原因 | 対策 |
|---|---|---|
| 表面に気泡の跡（小さな穴）が残る | 注入時に勢いよく注いで空気を巻き込んだ | 型の縁を伝わせてゆっくり注ぐ。最初の一杯目は特にゆっくり |
| 型から抜くときに変形する・ひび割れる | 排泥後の待ち時間が短すぎた | 縁を軽く触って、へこまない硬さになるまで待つ。焦らない |
| 型から抜けない・くっついている | 型の内側の状態が悪い（傷・汚れ）、または泥漿が濃すぎて張り付いている | 型の内側を定期的に確認・清掃する。無理に引っ張らず、型を優しく揺すって隙間を作る |
| 厚みが左右で違う | 型の固定が甘く、注入中にズレた／型自体の吸水性が偏っている | ゴムバンドをしっかり固定する。型の劣化が疑われる場合は買い替えを検討 |

### 自主練習メニュー

1. 小さい型（箸置き程度の小さいパーツがあれば理想）で、注入→着肉→排泥→型抜きの一連の流れを、**時間を計りながら**一通りやってみる。
2. 同じ型で着肉時間を変えて（例：15分／20分／25分）3回試し、切って断面の厚みを比較し、自分なりの目安時間を作る。
3. 比重計の使い方に慣れるため、水と泥漿で数値の違いを実際に見比べておく。
4. 排泥のときの「傾け方」を、ゆっくり／速く、の2パターンで試し、内壁の仕上がりの違いを確認する。

### 生徒に教えるときのポイント

- **注入と排泥は必ず教員が横に付いて一緒に行う**。危険はないが、失敗すると1サイクル分の作業が無駄になるため、成功体験を優先する。
- 着肉待ちの20分は、生徒にとって手持ち無沙汰になりやすい時間なので、**「待っている間にやること」を先に指示しておく**（活動計画の「懸念5」参照）。
- 比重を測って「1.75です」と声に出させる作業は、報告の練習としてそのまま使える。数字を読むこと自体が生徒にとって新しい経験になる。
- 型抜きの瞬間（作品が出てくる瞬間）は、生徒が一番達成感を持てる場面。急がせず、ゆっくり見せる。

## 4. 焼成後の「磨き」作業（本焼き後、12/7に実施）

流し込み・たたら引きと並んで、生徒が主体的に取り組みやすい工程が**本焼き後の磨き**である。

### なぜ磨くのか

焼成のとき、作品の底（高台）には**釉薬を塗らない**（塗ると窯の棚板にくっついてしまうため）。
そのため、焼き上がった底はザラザラした状態のままで、そのまま売ると**手や机を傷つけたり、テーブルを傷つけたりする**。これを滑らかにする作業が「磨き」である。

### 手順

1. 焼き上がった作品の底を触って、ザラつきを確認する。
2. 水を含ませた砥石（または耐水ペーパーの中間番手→仕上げ番手の順）で、**底を円を描くように優しく研ぐ**。
3. 時々指で触って、ザラつきがなくなったか確認する。**ツルツルにする必要はなく、「触って痛くない」程度で十分**。
4. 研いだ後、濡れた布やスポンジで削りカスを拭き取る。

### 生徒に教えるときのポイント

- 水を使うので、**必ず水を張ったバケツ・濡らしたスポンジを用意**して、粉じんが舞わないようにする。
- この作業は**単純な反復動作で、失敗してもやり直しがきく**ため、集中が続きにくい生徒にも向いている。
- 「合格ライン」を教員があらかじめ触って確認し、生徒自身にも合否判定をさせる（「懸念点」の対応策と対応）。

## 5. 先生自身の練習ロードマップ（学期開始前）

| 時期 | やること |
|---|---|
| 2週間前 | 土練り（荒練り→菊練り）を、くず土で気泡が消えるまで繰り返し練習 |
| 10日前 | たたら引き→型はめ→スタンプまで、実際に使う型で一度通しでやってみる |
| 1週間前 | 流し込みを、時間を計りながら一通り体験。着肉時間を自分の型で確定させる |
| 3日前 | 磨きの合格ラインを自分の手で確認しておく（生徒に示す基準を決める） |
| 前日 | 第1回で見せる「完成見本」「割れた作品の実物」の準備、しごとカード等の印刷物一式を確認 |

一度通してやってみると、**「言葉で説明しにくいところ」が必ず見つかる**（力加減、タイミングなど）。
そこは無理に言語化せず、**生徒の手を取って一緒に動かす**支援に切り替えるのがよい。
