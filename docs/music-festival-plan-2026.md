# 音楽科 2学期学習計画（文化祭 12/12 まで）

高等部キボウグループ（13名）／週1コマ60分／T1＋T2（ピアノ）

※本ドキュメントでは生徒名を伏せ、学年・役割で記載する。

---

## 0. 確定条件

| 項目 | 内容 |
|---|---|
| 文化祭 | 12月12日 |
| 学部構成 | オープニング → ユメグループ発表 → キボウグループ発表 → 全員合唱 |
| キボウ単独枠 | 8分程度 |
| キボウ内の3年生 | 4名（学部3年生は全8名。残り4名はユメ側） |
| ウクレレ曲 | カントリーロード（既習）＋ 糸（新規）の2曲 |
| 追加練習枠 | 文化祭3週間前から 週3回 × 30〜60分 |
| 既習コード | C(赤) / Am(青) / F(黄) / G7(緑) |
| 学部テーマ | 自分で決める、自分で選ぶ、仲間とともに創り出す |

## 1. 設計の核

### 1-1. 替え歌をキボウ枠から外し、オープニングへ移す

8分枠にウクレレ2曲＋替え歌を詰めると「間」が消え、生徒が輝くタメと拍手の時間がなくなる。
また学部3年生8名のうちキボウ所属は4名のみのため、キボウ枠だけを設計しても残り4名は輝かない。

替え歌をオープニング（学部全体）へ移すことで、以下が同時に解決する。

1. 8分の尺の問題
2. 3年生8名全員の見せ場
3. 音楽の時間をウクレレに集中できる（毎時間20分死守が可能になる）

### 1-2. 2曲は「組曲」として語りでつなぐ

カントリーロードと糸を独立した2曲として並べず、生徒の語りでつなぐ1本の流れにする。
8分に2曲入れても散らからない。

### 1-3. 土台はT2ピアノ＋歌

ウクレレが鳴らない生徒がいても曲が崩れない構造にする。これが本番最大の安全弁。

---

## 2. 本番の設計

### 2-1. オープニング案（学部全体）「選んで出てくる」

- 替え歌のイントロが鳴る
- 3年生8名が袖のテーブルから自分で選んだ物（ウクレレ／タンバリン／マイク／旗／帽子など）を持って一人ずつ登場
- 一人一言（自分の言葉。紙を見てよい）
- 全員でサビ

本番でのぶっつけ即興ではなく「選ぶところまでが本番」とすることで、
カオスにせずに主体性だけを残す。登場順はランダムでも成立する。

### 2-2. キボウ発表 8分（実尺は7分で作る）

拍手と転換で本番は必ず1分伸びるため、7分で構成する。

| 時間 | 内容 | 担当 |
|---|---|---|
| 0:00–0:40 | 語り①「4月からウクレレを始めました」＋会場へ手拍子のお願い | 語り手2名 |
| 0:40–3:00 | カントリーロード　1番：A班ウクレレ／B班歌　2番：交代 | 全員 |
| 3:00–3:30 | 語り②「もう1曲、僕たちが選んだ曲です」 | 語り手1名 |
| 3:30–6:00 | 糸　1番：B班ウクレレ／A班歌　2番：交代／Cメロは希望者ソロ | 全員 |
| 6:00–6:40 | 最後のサビ（生徒が決めた形／会場も一緒に） | 全員＋会場 |
| 6:40–7:00 | 締めの言葉 | 3年生 |

会場巻き込みは「手拍子を客席に教えに行く係」を2名置き、生徒発の演出として成立させる。

## 3. 教師の意図と生徒の裁量

第1回で生徒にこの表を提示する。裁量の範囲が見えると生徒は安心して大胆になる。

| 教師が決める | 一緒に決める | 生徒が決める |
|---|---|---|
| 8分という尺 | ステージのテーマ（合言葉） | 弾くか歌うか（A班／B班） |
| 2曲やること | 曲順 | Cメロのソロに出るか |
| 2班交代の仕組み | 会場の巻き込み方 | 最後のサビの形 |
| 安全・時間管理 | 替え歌の元曲 | 語りの言葉／衣装／立ち位置 |

## 4. 一人ひとりの席（役割メニュー）

13名全員に必ず1つ以上の役が当たるようにする。複数兼務可。

- ウクレレ隊（前半／後半で交代）
- ボーカル隊（前半／後半で交代）
- 語り手 3枠
- Cメロソロ（希望者 1〜3名）
- 最後のサビの合図を出す人 1名
- 会場巻き込み係 2名
- 衣装・小道具リーダー
- 音源ときっかけ係（T2と組む）

3年生4名には「最後に決める権利」を渡す（最後のサビの形を決める会議の進行、締めの言葉）。
ただし押しつけない。

## 5. 替え歌 歌詞（2026年8月確定）

元曲「女々しくて」。サビは音数を原曲に合わせ、A・Bメロも実際の音の感じに合わせて調整済み。
1番のみで小学部→中学部→高等部→全校の文化祭を歌い、2番は各学部の「ふだんの良さ」を生徒が出して作る。

### 5-1. 1番（確定版）

| パート | 歌詞 |
|---|---|
| フック | ぶんかさい　ぶんかさい　ぶんかさい　サイコー |
| Aメロ（小学部） | しょうがくぶが とびだしたよ／ちいさなてで おおきなこえ／つぎはなにが おこるのかな／まだだれもしらない |
| Bメロ（中学部） | ちゅうがくぶの てづくりぶたい／セリフもいしょうも じぶんたち／なんどもなんども れんしゅうした |
| プリサビ（高等部） | こうとうぶは おんがくでしょうぶだ／うたとえんそう とどけたい／ユメとキボウ ちがうからいい／なかまとつくるよ |
| 大サビ（全校） | ぶんかさい ぶんかさい／みんながしゅやく／ぶんかさい ぶんかさい／のびのびわらってて／ぶんかさい ぶんかさい／さあはじまるんだ ぼくらのステキな |
| ラストのフック | ぶんかさい　ぶんかさい　ぶんかさい　サイコー |

### 5-2. 2番（生徒作詞ワーク）

出だしは固定し、後半だけ生徒が埋める。大サビの「ぶんかさい ぶんかさい」（×3）と「ぼくらのステキな」は1番と同じで固定。

| パート | 固定部分 | 埋める音数 |
|---|---|---|
| Aメロ（小学部） | しょうがくぶは＿＿＿ | 6／12／12／9 |
| Bメロ（中学部） | ちゅうがくぶは＿＿＿ | 7／13／14 |
| プリサビ（高等部） | こうとうぶは＿＿＿ | 9／12／13／8 |
| 大サビ（全校） | ぶんかさい ぶんかさい（固定）×3＋ぼくらのステキな（固定） | 7／9／8 |

授業では「音数を手拍子で数える」こと自体を活動にする。出た言葉は例文より必ず優先する。

## 6. 授業計画（音楽14回想定）

方針：ウクレレ20分は12回すべてで死守。文化祭ラボ25分の中で、2番の作詞を9月末〜10月に少しずつ進め、直前に詰め込まない。

### 毎回の型（60分）

| 時間 | 活動 |
|---|---|
| 5分 | DJコーナー |
| 7分 | 歌唱（本番曲を歌う） |
| 20分 | ウクレレ（死守） |
| 25分 | 文化祭ラボ |
| 3分 | ふりかえり |

歌唱枠を本番曲に充てることで、練習時間を別に確保せずに済む。

### 第1期 9月：土台をつくる

| 回 | ウクレレ20分 | 文化祭ラボ25分 |
|---|---|---|
| 9-① | カントリーロード復習 | 枠の説明（8分・オープニング・全員合唱）＋裁量の表を提示＋アンケート実施 |
| 9-② | 糸 楽譜配布・色塗り | アンケート結果を模造紙で全部返す（否定なしで並べる） |
| 9-③ | 糸 Aメロ | 替え歌1番（確定版）を教師が披露し、感想を聞く |
| 9-④ | 糸 サビ | 2番作詞①：手拍子で音数を数える練習＋小学部のいいところを出し合う |

### 第2期 10月：みんなでつくる

| 回 | ウクレレ20分 | 文化祭ラボ25分 |
|---|---|---|
| 10-① | 2曲通し | A班／B班を自分で選ぶ（弾く／歌う）＋2番作詞②：中学部のいいところ出し合い→Bメロ仮確定 |
| 10-② | 班別練習 | ★2番作詞③：高等部のいいところ出し合い→プリサビ仮確定（自分たちを語る一番大事な回） |
| 10-③ | 交代の練習 | 2番作詞④：大サビ確定＋通して歌ってみる／【期限】替え歌2番の最終形を確定 |
| 10-④ | Cメロ試し弾き | 語りの言葉集め（付箋）＋役割メニュー決定／【期限】構成表を完成させる |

### 第3期 11月：仕上げる

| 回 | ウクレレ20分 | 文化祭ラボ25分 |
|---|---|---|
| 11-① | 通し前半 | 1回目の通し＋録画 |
| 11-② | 弱い箇所だけ | 録画を見る → 生徒が改善点を出す |
| 11-③ | 通し | 最後のサビの形を3年生中心に決定＋2番の清書 |
| 11-④ | 通し | 会場巻き込みの練習（客席に人を置いて実験） |

### 第4期 11月下旬〜12/12：磨く

音楽2回＋学部枠（週3回×3週＝9枠）。

- 音楽2回：ウクレレの音を仕上げることだけに使う（新しいことは入れない）
- 学部枠：衣装・小道具づくり、オープニング全体練習（ユメ・キボウ合同で2番を教え合う）、全員合唱、立ち位置合わせ
- 12月上旬にリハーサル1回、前日に軽く1回

## 7. アンケート（第1期の要）

方針：教師の案は一切見せない。名前は「書きたい人だけ」。

完全無記名だと拾った意見を本人と育てられない。
「書いても書かなくてもよい」にすることで、自由さと追跡可能性を両立する。
書くのが苦手な生徒のために ○つけ＋自由記述の2層構成にする。

1. ステージが終わったとき、どんな気持ちになりたい？
   （かっこいい／おもしろい／かんどう／たのしい／びっくり／自由記述）
2. やってみたいこと・面白そうなことを、いくつでも
3. 自分がやりたい役（複数可）
   ウクレレ／歌／しゃべる／おどる／衣装をつくる／道具をつくる／音や照明／決めるのを手伝う／まだ決めない
4. 見に来た人に、何を伝えたい？
5. これだけはイヤだ、ということ

5番を必ず入れる。「やりたくない」を言える場が「やりたい」を出せる前提になる。

---

## 8. 教師の負担を抑える仕掛け

- 9月中に教師が作るものは3点のみ
  1. アンケート用紙
  2. 「糸」の色塗り楽譜（C=赤／Am=青／F=黄／G7=緑）
  3. 替え歌1番のサンプル（確定済み）
- 伴奏はガズレレ動画（等倍速）を継続。本番はT2ピアノ
- 衣装・小道具は学部枠へ完全に外出し
- 通しは毎回タブレット固定で録画し、講評せず流すだけにする（生徒が自分で気づく）
