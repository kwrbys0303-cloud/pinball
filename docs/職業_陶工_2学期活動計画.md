# 職業（陶工）2学期 活動計画案（改訂版）

- **対象**：高等部 5名（全員が今年度から陶工に取り組む）
- **時間**：月曜（一部火・水）2時間＝50分＋休憩10分＋50分
- **回数**：全13回（9月3回／10月3回／11月5回／12月2回）
- **ゴール**：12月12日（土）文化祭で、自分が作った焼き物を自分で売る

---

## 0. 改訂のポイント

前回案からの一番大きな変更は、**窯を1サイクルに単純化した**ことである。

- **11月10日＝素焼き締切**：この日までに、成形（たたら引き・流し込み）と乾燥・縁の仕上げまで全部終わらせる。
- **11月25日＝本焼き締切**：この日までに、全員の釉薬掛けを終わらせる。
- **本焼き後（12/7）は、ほぼ「磨く作業」**：窯から出た商品の底（高台）を磨いて仕上げ、値付け・袋詰めをする。
- **接客練習はほぼ行わない**：1学期の実習ですでに練習済みのため、12/7に台詞の確認だけ短く行う。

窯を焚くのが2回（素焼き1回・本焼き1回）だけになるので、前回案より運用がシンプルになっている。

## 2. 毎回のお決まりの手順（100分＋休憩10分）

| 時刻 | 時間 | 内容 | ねらい |
|---|---|---|---|
| 0:00–0:08 | 8分 | **朝礼**：身支度→「今日の仕事ボード」確認→**一人ずつ今日の目標を声に出す** | 見通し／報告の型 |
| 0:08–0:43 | 35分 | **作業①**（グループ別のメイン作業） | 集中してやりきる |
| 0:43–0:50 | 7分 | **中間報告**：手を止めて道具を置く→一人ずつ「ここまでできました」 | できたことを伝える |

## 3. グループ編成と作業内容

### Aグループ（3名）— 皿・椀

| 工程 | 内容 |
|---|---|
| 土練り | 荒練り→菊練り（教員が仕上げ確認） |
| たたら引き | たたら板（厚み7mm）＋切り糸で土のシートを引く |
| 型起こし | 石膏型／素焼き型にシートを被せ、なで革で密着させる |
| スタンプ・オリジナリティ | シートが平らなうちに、または型にはめた直後にスタンプを押す（詳しくは陶工ガイド参照） |
| 乾燥 | 半乾燥（革状）まで型のまま乾燥棚へ |
| 縁の切り取り・みがき | カンナ・切り出しで縁を切り落とし、なめし革→耐水ペーパーで角を落とす |
| 高台・仕上げ | 高台の削り出し／サインを入れる |

### Bグループ（2名）— 箸置き

| 工程 | 内容 |
|---|---|
| 型抜き | Aグループが引いたたたらシートから、クッキー型で抜く |
| かたち付け | 中央を指で押す／棒に掛けて反らせる／スタンプを押す |
| 縁みがき | 半乾燥でスポンジ、乾燥後に耐水ペーパー |
| 仕上げ | 5個1セットで並べて確認 |

**支援ポイント**：「5個で1セット」という小さな完了単位を作る。道具は使う分だけ箱に入れて渡す。完成見本は手元の作業台に置く。集中が切れたら後半をメンテナンス作業に振り替える。

## 4. 「報告・相談」を育てる仕掛け（前回案から継続）

### 3つの合言葉
「はじめます」（着手）／「**わかりません**」（相談・一番ほめる）／「できました」（完了）

### しごとカード（1人1枚／毎回）
```
第◯回  ◯月◯日   名前 ________
【今日の仕事】  □たたら  □型おこし  □ふちけずり  □ふちみがき
                □流しこみ  □釉薬  □みがき  □メンテナンス（      ）
【目標】______個 ／【できた】______個
【相談】 □「わかりません」と言えた（____回） 何を相談した？ ____________
【ひとこと報告】____________________________
先生から ▶                          サイン ______
```

### 3分ルール（砂時計）
各作業台に3分砂時計。「3分考えてわからなかったら先生を呼ぶ」を明文化・掲示。

### 報告シール台紙
報告・相談1回＝シール1枚。10枚で「陶工マイスターカード」。文化祭の販売担当は、マイスターカードを持っている人から。

### メンテナンス作業は「作業依頼書」の形で渡す
```
【作業依頼書】No.____
依頼元： ________先生    内容：____________________
期限：   ◯月◯日        担当：____________
＜完了報告＞ 終わりました：◯月◯日   気づいたこと：__________  受領サイン：______
```
学期はじめに依頼を数件ストックしておく。ストック例：陶工室の棚整理／釉薬バケツの整理／体育館の掃除／体育用具の点検／乾燥棚の清掃／石膏型の洗浄・乾燥。

## 6. 懸念点と対応策

| # | 懸念 | 対応策 |
|---|---|---|
| 1 | **2時間の集中が持たない**（特に2名） | 35分ブロック×2＋中間報告7分で必ず手を止める／「5個で1セット」の完了単位／切れたらメンテナンス作業に振替 |
| 2 | **11/10までに成形が終わらない** ★最大 | 締切を学期はじめから掲示・カウントダウン／10/13・10/19を追い込み回として遅れ回収に使う／個人別カウント表で遅れを可視化 |
| 3 | **窯が1サイクルしかなく、遅れがそのまま致命傷になる** | 目標を販売予定数の1.5倍に設定し、多少の遅れでも最低限の数を確保／どうしても間に合わない場合は「3学期用」と割り切る前提を最初に共有しておく |
| 4 | **釉薬掛けが実質2回（11/16・11/25）しかない** | 「浸し掛け」中心にして1人あたりの所要時間を短縮（陶工ガイド参照）／11/16に多めの時間を確保し、11/25は残りと最終チェックに専念 |
| 5 | **流し込みの待ち時間（着肉20分）で手持ち無沙汰になる** | 「待ちの間の仕事」を朝礼で先に指定する（縁みがき・箸置き仕上げ）／泥漿は必ず前回の後半で仕込む |
| 6 | **型の数が足りず、5人が同時に作業できない** | 2班交替制／担当表を先に作って掲示し「今日は自分の番ではない」を事前に伝える |
| 7 | **A・B間の進度差・自己肯定感** | 箸置きも同じ売り場・同じ値札フォーマットで並べる／値段会議・値札書き・磨きは全員同じ役割／評価は報告・相談・集中で見ると本人にも伝える |
| 8 | **窯での破損（商品ゼロの子が出る）** | 目標個数を1.5倍に／「窯で割れるのはよくあること」を9月のうちに実物を見せて伝える／失敗作も「練習作品」として持ち帰らせる |
| 9 | **釉薬の失敗（厚すぎ・薄すぎ・棚板に融着）** | 撥水剤（高台処理）は教員が事前に／浸し掛けは1人ずつ、時間を数えて統一（陶工ガイド参照） |
| 10 | **磨き作業（12/7）が1回に集中しすぎて終わらない** | 磨きの合格ラインを「手で触ってザラつかない」程度に設定し完璧を求めない／終わらなければ12/12当日朝に予備時間を確保 |
| 11 | **欠席で工程が飛ぶ** | 個人別カウント表で管理／欠席者の作品はビニールを掛けて進行を止めて預かる |
| 12 | **文化祭後（12/15）のモチベーション低下** | 「成果を数える日」にする（売上集計・グラフ・お礼状）／3学期用の流し込み作品を見せて次への接続を作る |

## 7. 評価ルーブリック（4つの目標に対応）

| 目標 | ◎ | ○ | △ |
|---|---|---|---|
| **報告や相談の大事さを理解する** | なぜ報告するのかを自分の言葉で説明できる | 声をかけられれば報告する必要性がわかる | 促されて報告する |
| **わからないことは自分から相談する** | 手が止まって3分以内に自分から呼べる | 砂時計を見て、促されれば呼べる | 黙って止まっていることが多い |
| **できたことをきちんと伝える** | 「何を・いくつ」まで含めて報告できる | 「できました」と伝えられる | 完成を見せることはできる |
| **集中してやりきる** | 35分の作業ブロックを最後までやりきる | 中間報告で立て直せば最後まで持つ | 15〜20分の単位でやりきれる |
