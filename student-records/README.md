# student-records

生徒の授業記録・振り返りを蓄積するためのディレクトリです。将来的に成績表作成に活用することを目的としています。
（本リポジトリ本来のピンボールゲームとは内容的に無関係ですが、記録先として利用しています。）

## 構成

- `records/`: 授業ごとの振り返り記録（`日付_授業名.md`）。教師自身の振り返りや事後研究会の評価もここに含みます。
- `students/`: 生徒ごとの記録。同じ生徒について複数の授業の様子を時系列で追記していきます。

## 命名規則

- クラス／グループ名の後に番号がつく場合（例: 国数1番）、`students/` 配下では `koku-suu-01.md` のように英数字の連番で管理します。
