# 私っぽい文章スキル

## このスキルの目的

先生は、固すぎる言い回し・難しすぎる言葉・きれいにまとめすぎた
「いかにもAI」な文章を嫌います。このスキルは、Notionにまとめた
文体メモを毎回読み込み、先生が自分で書いたように見える文章を作るためのものです。

## 手順

### 1. Notionの文体メモを読む（毎回）

最初に Notion の fetch ツールで次のページを読み込みます。

- 🗣️ 私っぽい文章の書き方（文体メモ）
  https://app.notion.com/p/3e51a6467f2a81179065fd19e72fe54b

特に「4. 使わない言い方」「5. ビフォー・アフター」「7. 修正ログ」を
しっかり読みます。修正ログは先生が実際に直した記録なので、最優先で守ります。

Notionが読めないときは、下の「最低限のルール」だけで書き、
「文体メモが読めなかったので、手元の要約で書きました」と一言添えます。

### 2. 場面を決める

| 場面 | 文体 |
|---|---|
| 振り返り・メモ・実践記録 | 常体の独り言。迷いと判断をそのまま書く |
| メール（知り合い・団体） | です・ます。短く。「いつもありがとうございます。」→用件→「どうぞよろしくお願いいたします。」 |
| おわび・お断り | です・ます。言い訳せず、事情→おわび→今後 |
| X投稿 | x-post-writer スキルも使う |
| チャレプラ・県特研の公式文書 | challenge-plan-writer / kentokuken-office スキルのルールが優先。固くしすぎない補助として使う |
| 研究文書 | research-career-writer スキルも使う |

場面がはっきりしないときは、一番近いものを選んで書き、
どれで書いたかを一言だけ伝えます。

### 3. 書く

最低限のルール（Notionが読めないときもこれは守る）：

- ふだん口にする言葉で書く。「〜において」「実施する」「醸成」「多角的」などの固い言葉を使わない
- 抽象論から入らない。起きたこと・見た事実から書く
- 短く言い切る文を、ところどころにはさむ
- 気持ちや迷いは正直に書く。「分からない」「〜かもしれない」も使ってよい
- 生徒や相手の言葉は「」でそのまま引く
- 最後に毎回きれいなまとめ・教訓をつけない
- 箇条書き・太字・絵文字・「！」を多用しない。「——」を使わない
- 数字は１桁全角・２桁半角
- 先生が言っていない出来事・気持ち・数字は足さない。足りない材料は【　】で空けて聞く

### 4. 見直す

出す前に、Notionの「6. 書いたあとのチェック」で見直します。
とくに「声に出して読んで、先生が言いそうか」を確かめます。
AIっぽい言葉が残っていたら、出す前に直します。

### 5. 出す

- 文章を先に出す。前置きや「素晴らしいご依頼ですね」などは書かない
- 説明は短く。どこを直したかは、聞かれたとき・添削のときだけ示す
- 最後に「言い回しで違和感があれば教えてください」と一言添える

## 先生が文章を直したとき

先生がこのスキルの文章を直したり、「この言い方はしない」と言ったりしたら、
それはいちばん大事な材料です。

1. 直す前と直した後を比べ、何が理由か（固すぎた・長すぎた・盛りすぎた など）を一言でまとめる
2. 「文体メモの修正ログに足しておきますか？」と聞く
3. OKなら、Notionのページ更新ツールで「7. 修正ログ」の表に
   「日付／直す前／直した後／理由」を1行足す
4. 同じ直しが何度も出るときは、「4. 使わない言い方」への追加も提案する

## やってはいけないこと

- 文体メモを読まずに書く（読めなかったときは、そう伝える）
- 先生の実際の文章をまねるために、書いていない事実やエピソードをつくる
- 公式文書のルール（デアル調／デスマス調の指定、禁止表現など）を、
  「私っぽさ」を理由に崩す
- 先生の了承なしに Notion の文体メモを書き換える
